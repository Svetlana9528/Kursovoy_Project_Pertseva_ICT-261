# Курсовой проект: Мониторинг реактора: активность катализатора

## Индивидуальный вариант №28

## Описание проекта
Программа предназначена для мониторинга технологического процесса химического реактора (Этап 1 — Оперативный мониторинг). Она преобразует текущее значение активности катализатора X в расчётный показатель повышения Q(X), выполняет автоматический контроль отклонения от номинального значения и выводит технологический статус пользователю в режиме реального времени.

## Входные данные
* **Параметр X:** активность катализатора, %. Математически обрабатывается как вещественное число (`float`).
* **Рабочий диапазон параметров:** от 0.0% до 100.0%.
* **Номинальное (целевое) значение Q:** 50.0%.
* **Допустимый предел технологического отклонения:** ±10.0% (интервал нормы: от 40.0% до 60.0%).
* **Количество измерений в цикле мониторинга:** $N = 40$.

## Формула преобразования Q = f(X)
Расчёт показателя эффективности выполняется по кусочно-заданной функции:

```latex
Q \(= \begin{cases} 6.0 \cdot \sqrt{\vert{}X - 64.0\vert{}} + 5.0, & \text{если } X < 65.0 \\ 2.0 \cdot (X - 77.5) + 50.0, & \text{если } 65.0 \le X \le 90.0 \\ 0.25 \cdot (X - 90.0)^2 + 55.0, & \text{если } X > 90.0 \end{cases}\)
```

## Ручной расчёт для верификации

Для подтверждения корректности алгоритма выполнен проверочный расчёт контрольных точек для каждого из трёх участков функции:

**1. X = 60.0 (Первый участок, $X < 65.0$):**
$Q(60.0) = 6.0 \cdot \sqrt{|60.0 - 64.0|} + 5.0 = 6.0 \cdot \sqrt{4.0} + 5.0 = 6.0 \cdot 2.0 + 5.0 = 17.0\%$.
*Оперативный контроль:* $|17.0 - 50.0| = 33.0 > 10.0$ $\rightarrow$ `Критическое отклонение!`.

**2. X = 77.5 (Второй участок, $65.0 \le X \le 90.0$):**
$Q(77.5) = 2.0 \cdot (77.5 - 77.5) + 50.0 = 2.0 \cdot 0.0 + 50.0 = 50.0\%$.
*Оперативный контроль:* $|50.0 - 50.0| = 0.0 \le 10.0$ $\rightarrow$ `Норма.`.

**3. X = 110.0 (Третий участок, $X > 90.0$):**
$Q(110.0) = 0.25 \cdot (110.0 - 90.0)^2 + 55.0 = 0.25 \cdot (20.0)^2 + 55.0 = 0.25 \cdot 400.0 + 55.0 = 100.0 + 55.0 = 155.0\%$.
*Оперативный контроль:* $|155.0 - 50.0| = 105.0 > 10.0$ $\rightarrow$ `Критическое отклонение!`.

## Оперативный контроль
Каждое рассчитанное значение Q автоматически сопоставляется с технологическими границами:
* Если абсолютное отклонение от номинала больше допустимого ($|Q - 50.0| > 10.0$), система немедленно выводит предупреждение: `Критическое отклонение!`.
* Если показатель находится в пределах допуска ($|Q - 50.0| \le 10.0$), система сообщает о стабильности процесса: `Норма.`.

## Структура программы
Программа спроектирована по модульному принципу разделения ответственности и реализована на языке C (стандарт C99).
* `calc_q(float x)` — математический модуль: вычисление показателя Q по трём участкам кусочной функции.
* `check_state(float q)` — логический модуль: контроль отклонения текущего значения от номинала.
* `read_x(int index, float *x)` — модуль ввода: безопасное чтение параметров из потока stdin с защитой от сбоя формата.
* `print_state(int state, float q)` — модуль интерфейса: вывод результатов и текущего технологического статуса процесса.
* `print_welcome()` — модуль инициализации: вывод стартового окна программы и её технологического назначения.
* `run_verification_tests()` — модуль самодиагностики: автоматический фоновый тест верификации контрольного примера.
* `main()` — главный диспетчер: настройка локали, выполнение автотеста и организация управляющего цикла мониторинга.
  
В коде используются стандартные управляющие конструкции `if / else if / else`, функции ввода-вывода `scanf / printf / puts`, а также специализированные математические функции `sqrtf`, `powf` и `fabsf` из библиотеки `<math.h>`.
