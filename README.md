# Курсовой проект 

## Вариант 28

### Постановка задачи
Составить программу, которая, согласно указанным формулам при разных значениях «х», будет вычислять показатель повышения \(Q(X)\) (в процентах) химического реактора, а также средний абсолютный прирост между соседними значениями, максимальный прирост и минимальный прирост из первых 15 получившихся значений.
